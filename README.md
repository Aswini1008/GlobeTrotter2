
# 🌍 GlobalTrotter – Smart Travel Planning Platform

GlobalTrotter is a **modern, image-rich travel planning web application** designed to help users **discover destinations, manage trips, and visualize journeys** through a clean and intuitive interface.

Built with a strong focus on **UI quality, usability, and reliability**, the platform ensures **no empty screens, no broken images, and a smooth user experience**—making it ideal for real-world use and hackathon evaluation.

---

## 🚩 Problem Statement

Travel planning applications often suffer from:

* Poor UI/UX design
* Missing or broken destination images
* Confusing navigation
* Lack of clarity in trip status and organization

These issues reduce user trust and engagement.

---

## 💡 Our Solution

GlobalTrotter solves these problems by:

* Ensuring **image-perfect UI** across all screens
* Categorizing trips into **Ongoing, Upcoming, Completed, and Drafts**
* Providing **city-accurate destination visuals**
* Offering a **clean sidebar navigation** and intuitive dashboard
* Delivering a **dark-mode, responsive, premium experience**

---

## ✨ Key Features

* 🌆 Destination discovery with relevant images
* 🧳 Smart trip listing with status-based categorization
* 🖼️ Guaranteed images for every card and screen
* 🔍 Search, filter, and sort trips easily
* 🎨 Dark-mode, responsive, modern UI

---

## 🛠️ Tech Stack

* **Frontend:** React + TypeScript
* **Styling:** Modern CSS / Tailwind CSS
* **Images:** Unsplash Source API (non-expiring, reliable)
* **Backend (Planned):** Firebase (Auth, Firestore, Storage)

---

## 🚀 Getting Started

```bash
npm install
npm run dev
```

The application runs locally and is fully responsive.
