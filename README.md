

# GlobalTrotter

GlobalTrotter is a **modern travel planning web application** focused on **clean UI, image-rich destination discovery, and intuitive trip management**.
The application ensures **every screen and card displays relevant images**, delivering a polished and production-ready experience.

---

## Key Features

* Destination discovery with city-accurate images
* Ongoing, upcoming, completed, and draft trip views
* Image-perfect UI (no empty or broken visuals)
* Dark-mode, responsive, modern design
* Search, filter, and sort functionality

---

## Tech Stack

* React + TypeScript
* Unsplash Source API
* Optional: Firebase (Authentication, Storage, Firestore)

---

## Getting Started

```bash
npm install
npm run dev
```
