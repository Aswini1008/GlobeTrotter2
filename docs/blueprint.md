# **App Name**: GlobeTrotter

## Core Features:

- User Authentication: Secure user login and registration using Firebase Authentication (Email/Password).
- Trip Planning: Plan multi-city trips with start and end dates, budget, and city-specific stops.
- Itinerary Builder: Visually build and reorder trip itineraries, adding cities and activities.
- Budget Management Tool: Real-time budget breakdown with total estimated cost, cost per day, and cost per city, using AI to estimate expenses and suggest budget adjustments to ensure your trip aligns with financial targets.
- Itinerary Visualization: View trip itineraries in a day-wise or city-wise timeline with activity blocks and costs.
- Data Storage: Persist user-specific trip data in Firestore with collections for users, trips, stops, and activities.
- Public Sharing: Share itineraries publicly in a read-only view.

## Style Guidelines:

- Primary color: Teal (#20A499) to evoke a sense of calm and travel.
- Background color: Light gray (#F0F0F0) for a clean and neutral backdrop.
- Accent color: Orange (#FF8300) for call-to-action buttons and important alerts.
- Font pairing: 'Poppins' (sans-serif) for headlines and 'PT Sans' (sans-serif) for body text.
- Use consistent, modern icons to represent different trip activities and categories.
- Card-based layout with generous spacing for a clean and organized UI.
- Subtle transitions and animations for dynamic updates and user interactions.
